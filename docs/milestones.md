# 阶段记录

## M1：分享授权与可恢复生成后端（2026-10-05）

已实现注册/登录/退出、角色设定、默认私有日记、精确版本分享/撤回、关联会话与消息、来源记忆、
虚构角色日记任务、超时与显式重试、操作回执、游标分页、PostgreSQL 迁移和 OpenAPI。
默认模型适配器关闭；测试替身只在测试中注入，没有对外生成示例回复或发起真实模型调用。
业务接口与数据操作独立于页面，设计理由、权限边界和连续性取舍见 ADR-002。

本地验证：Node.js 24.17.0、TypeScript 5.9、真实 PostgreSQL 18.4；`npm test` 19/19 通过，无跳过。
覆盖：身份与账户/角色隔离、严格输入、并发版本冲突、大小写 UUID/请求字段排序、幂等撤回重放、
私人记录排除、修改后重新分享、派生记忆失效、生成中的撤回/设定变更、过期 worker、超时、重复 worker、
旧轮次重试拒绝、角色日记只读、模型无效输出、相同时刻消息分页、事务中途失败回滚、应用与数据库重启、契约一致性。
临时测试数据与集群已清理。生成测试检查真实服务端组装的上下文，但供应商是测试适配器，不代表真实 AI 效果。

首轮编译发现测试使用的 Promise 类型超出当前 ES2023 配置，改为本地 deferred helper 后完成 17 项测试。
自查发现较早关联角色日记可能被“最近五篇”筛选遗漏，修正为优先当前消息与用户选中记录，新增长文本预算及无效结果测试后，19 项完整重跑通过。
SQL 迁移固定 LF 换行，避免跨平台检出的换行差异改变迁移校验值。

已配置 GitHub Actions 在后端/契约更新时执行同一套真实数据库测试。推送、远端验证和本地运行结果另补。
本阶段未实现：Flutter 客户端、真实供应商适配、真实 AI 陪伴效果、多日语义检索、自动记忆提取、
主动消息/定时任务、生产部署，以及 Android / iOS 验收。
