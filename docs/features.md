# 当前功能清单

| 能力 | M1 后端状态 | 限制 |
| --- | --- | --- |
| 注册、登录、退出 | 已实现，令牌摘要入库 | 未做密码找回、邮箱验证和账户删除 |
| 角色设定 | 创建、读取、更新、分页、版本冲突 | 无 Flutter 页面 |
| 个人日记 | 默认私有，创建、读取、修改、分页 | 无删除接口；未做离线同步 |
| 分享与撤回 | 逐篇、逐角色、精确版本，支持并发冲突 | 修改原文后重新分享 |
| 关联对话 | 从获准日记或有效角色日记发起；消息持久化 | 单会话串行生成，无流式展示 |
| 角色日记 | 任务生成、固定保存、只读查询，明确虚构 | 默认服务商未配置，无真实生成效果 |
| 记忆 | 带来源的摘要，可查看、修正、失效 | 手动维护；无自动提取和向量检索 |
| 上下文筛选 | 账户/角色隔离，撤回和原文变更后排除旧内容 | 保守退出旧代次对话，可能减少连续性 |
| 生成恢复 | 持久任务、超时、过期 worker 防护、显式重试 | 已发往供应商的请求不能撤回 |
| API 契约 | REST / OpenAPI、稳定错误、分页和操作回执 | 生产扩容、费用额度与监控待完善 |

尚未实现：Flutter 客户端、Android / iOS 验收、真实模型接入、跨多日陪伴效果评估、后台主动消息、定时生成、生产部署。
测试适配器只存在于测试代码，不作为可选运行服务商对外提供。
